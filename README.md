# GitHub Supervisor Learning Program

> Git 입문 학생 팀을 위한 **학습형 협업 코치 봇**
> 로컬 LLM(Ollama)이 팀의 GitHub 활동을 지켜보며, 위험한 실수와 나쁜 습관을 **원인 설명 + 복구 방법**과 함께 알려줍니다.

## 프로젝트 소개

Git에 익숙하지 않은 사람은 다음과 같은 실수를 자주 합니다.

- **위험한 실수**: `main`에 직접 push, force push, 비밀번호·키 업로드, 리뷰 없이 병합
- **나쁜 습관**: 규칙에 맞지 않는 브랜치명·커밋 메시지, 방치된 PR, 한 사람에게 몰린 리뷰

이 프로젝트는 이런 행동을 감지해 단순히 막거나 지적하는 데서 끝나지 않고, **왜 문제인지와 어떻게 되돌리는지**를 설명해 주는 학습 도구를 목표로 합니다.

## 핵심 기능

| # | 기능 | 설명 |
|---|---|---|
| 1 | **CLI 위험 행동 차단** | 위험한 Git 명령어 입력 시 실행 전에 가로채고, 위험한 이유를 바로 설명합니다. 차단할지 그대로 실행할지는 사용자가 선택합니다. |
| 2 | **Git Flow 규칙 감지** | GitHub API로 브랜치명·PR 대상 브랜치·커밋 메시지 등의 규칙 위반을 감지하고 대시보드에 알립니다. |
| 3 | **협업 대시보드 + 복습 퀴즈** | 팀 협업 현황을 통계로 시각화하고, 본인이 저질렀던 실수 로그를 바탕으로 퀴즈를 만들어 복습할 수 있습니다. |

부가 기능(검토 중)
- PR 한국어 학습형 리뷰: diff를 읽고 문제가 있는 줄에 "무엇이 왜 문제인지" 코멘트
- 실시간 행동 알림: `main` 직접 push·force push 등을 디스코드 등으로 즉시 알림

## 차별점

- **대상**: 숙련 개발자용 도구(CodeRabbit 등)가 아닌 **Git 입문 학생 팀**용
- **방식**: 지적이 아니라 **원인 설명 + 복구 방법**을 알려주는 학습형
- **신뢰성**: **판정은 코드, 설명은 LLM** → LLM 환각으로 인한 오판 방지
- **범위**: 막기만 하는 GitHub 브랜치 보호와 달리 **PR 밖의 행동까지** 감지·기록
- **도그푸딩**: 우리 팀 레포에 직접 적용하며 개발 → 실제 사용 데이터가 곧 결과물
