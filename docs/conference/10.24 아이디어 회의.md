- 아이디어 최종 선출

[주제 제안]
학생/초보자로 구성된 팀의 GitHub 활동을 로컬 LLM(Ollama)이 지켜보며, PR을 리뷰하고 Git Flow 규칙 위반을 실시간으로 알려주는 협업 코치 봇

사용자의 위험한 실수(ex: main에 직접 push, force push, 비밀번호 업로드, 리뷰 없이 병합)이나, 나쁜 습관(이상한 브랜치명·커밋 메시지, 방치된 PR, 한 사람에게 몰린 리뷰)같은 것들을 알려주어, Git에 익숙하지 않은 사람/배워가고 있는 사람에게 도움이 되는 학습 도구

- 핵심 기능
PR 한국어 학습형 리뷰: diff를 읽고 문제점과 "왜 문제인지"를 해당 줄에 코멘트
Git Flow 규칙 검사: 브랜치명·PR 대상·커밋 메시지 위반 감지 및 병합 차단
실시간 행동 알림 + 대시보드: main 직접 push·force push 등을 즉시 디스코드 등으로 알리고, 팀 협업 통계 시각화

- 차별점:
대상: 숙련 개발자용(CodeRabbit 등)이 아닌 Git 입문 학생 팀용
방식: 지적이 아니라 원인 설명 + 복구 방법을 알려주는 학습형
로컬 LLM: 코드가 외부로 안 나가고 비용 0원 (X)
신뢰성: 판정은 코드, 설명은 LLM → 환각으로 인한 오판 방지
범위: 막기만 하는 GitHub 브랜치 보호와 달리 PR 밖의 행동까지 감지·기록
도그푸딩: 우리 팀 레포에 직접 적용해 개발하므로 실제 사용 데이터가 곧 결과물

CLI 메인 프로그램(로컬) or 상시 켜져있는 백그라운드형 프로그램
ollama 활용 gemma4 e2b -> 오픈소스
supabase, vercel -> 로그 확인용 대시보드
docker compose -> 컨테이너 3종류 이상 (만들어보면서 정하기)

---

핵심 기능 1 : CLI -> 위험한 행동(명령어 입력 시) 시 막고, 위험한 이유를 바로 설명. 블록/실행은 선택 가능.
핵심 기능 2 : Github api를 통해서 Flow를 감지하고, 규칙 위반 있을 시에 대시보드에 알림.
핵심 기능 3 : 대시보드에 팀 협업 현황을 통계 시각화 + 본인이 잘못했던 로그들 데이터로 퀴즈 생성해서 복습 가능.
